# JurisLink

JurisLink is a global cybercrime law and statutory strictness platform. It provides comparative legal intelligence across major world jurisdictions, tracking enacted penal statutes, mandatory breach notification deadlines, pending legislation awaiting gazette notification, and emerging AI cybercrime governance.

## What the Platform Does

- **Interactive Global Legal Map:** A responsive 2D world map visualizing cross-border cyber threat connections, statutory strictness heatmaps, and pending legislation hotspots across major jurisdictions.
- **Side-by-Side Jurisdictional Strictness Comparison:** Direct comparative analysis of national cybercrime frameworks, evaluating statutory incarceration maximums, corporate turnover penalties, mandatory breach reporting windows, and extraterritorial jurisdiction.
- **Pending & Unnotified Legislation Pipeline:** Dedicated tracking of statutes that have been passed by national legislatures but remain unnotified in official gazettes or await operative administrative rules.
- **AI Cybercrime & Synthetic Media Governance:** Comprehensive legal taxonomy and statutory matrix covering non-consensual deepfakes, AI voice cloning extortion, autonomous offensive malware, and foundation model training liabilities.
- **Grounded AI Legal Research Assistant:** Real-time legal intelligence powered by Groq Llama-3.3-70B integrated with Tavily Web Search API for grounded, citation-backed statutory research.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **UI & Styling:** Tailwind CSS
- **Language:** TypeScript
- **Icons:** Lucide React
- **Language Model:** Groq SDK (Llama-3.3-70B)
- **Web Search Engine:** Tavily Search REST API
